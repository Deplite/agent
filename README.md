# Deplite Agent

[Deplite](https://deplite.io)의 워크플로우를 내 서버에서 실행하는 Agent입니다.

자세한 사용법은 [Agent 안내](https://docs.deplite.io/docs/agent)와 [Deplite 문서](https://docs.deplite.io)를 참고해주세요.

## 설치

콘솔에서 1회용 설치 코드를 발급받은 뒤 아래 명령을 실행해주세요.

```sh
curl -fsSL https://deplite.io/install/agent \
  | DEPLITE_INSTALL_CODE=<1회용_설치_코드> sh
```
